# Turbo Cats — Android APK Build Guide

## What's in this folder

```
turbo-cats-android/
├── www/
│   └── index.html        ← Your complete game (ready to go)
├── capacitor.config.ts   ← Capacitor settings
├── package.json          ← Dependencies
├── android/              ← Generated by Capacitor (after step 3)
│   └── app/src/main/res/values/strings.xml
└── README.md             ← This file
```

## Prerequisites (install these first)

| Tool | Download | Notes |
|------|----------|-------|
| Node.js 18+ | https://nodejs.org | LTS version recommended |
| Android Studio | https://developer.android.com/studio | Includes SDK + JDK |
| Java JDK 17 | bundled with Android Studio | Or install separately |

After installing Android Studio, open it once and let it download the Android SDK.

## Build Steps

### Step 1 — Install dependencies
Open a terminal in this folder and run:
```bash
npm install
```

### Step 2 — Add the Android platform
```bash
npx cap add android
```
This creates the full Android project inside the `android/` folder.

### Step 3 — Sync your game files into Android
```bash
npx cap sync android
```
Run this any time you update `www/index.html`.

### Step 4 — Open in Android Studio
```bash
npx cap open android
```
Android Studio opens with the full project loaded.

### Step 5 — Build the APK in Android Studio

**For testing (debug APK — installs directly on your phone):**
- Menu → Build → Build Bundle(s) / APK(s) → Build APK(s)
- APK saved to: `android/app/build/outputs/apk/debug/app-debug.apk`

**For Play Store (release APK — requires signing):**
- Menu → Build → Generate Signed Bundle / APK
- Choose APK → Create new keystore (save it somewhere safe!)
- Fill in keystore details → Build
- APK saved to: `android/app/build/outputs/apk/release/app-release.apk`

## Install on your Android phone (debug APK)

1. On your phone: Settings → Developer options → Enable "USB debugging"
   - (To get Developer options: Settings → About phone → tap "Build number" 7 times)
2. Plug phone into PC with USB cable
3. In Android Studio: Run → Run 'app' — it installs and launches directly

OR transfer `app-debug.apk` to your phone and open it
(you may need to allow "Install unknown apps" in Settings → Security)

## Make it fullscreen (recommended for a game)

In Android Studio, open:
`android/app/src/main/res/values/styles.xml`

Add inside the main theme:
```xml
<item name="android:windowFullscreen">true</item>
<item name="android:windowLayoutInDisplayCutoutMode">shortEdges</item>
```

## Add a custom icon

Replace these files with your own 512×512 PNG resized to each size:
- `android/app/src/main/res/mipmap-hdpi/ic_launcher.png` — 72×72
- `android/app/src/main/res/mipmap-xhdpi/ic_launcher.png` — 96×96
- `android/app/src/main/res/mipmap-xxhdpi/ic_launcher.png` — 144×144
- `android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png` — 192×192

Or use Android Studio's Image Asset Studio:
Right-click `res` → New → Image Asset → Launcher Icons

## Uploading to Google Play Store

1. Build a **release** AAB (Android App Bundle) instead of APK:
   - Build → Generate Signed Bundle / APK → Android App Bundle
2. Go to https://play.google.com/console
3. Create a new app → Upload the `.aab` file
4. Fill in store listing (description, screenshots, rating)
5. Submit for review (~3–7 days)

A Play Store developer account costs a one-time $25 fee.

## Fastest path (5 minutes, no coding)

If you just want to test quickly without any setup:

1. Host `www/index.html` for free on GitHub Pages:
   - Create a repo at github.com → upload the file → Settings → Pages → Enable
   - Your URL: `https://yourusername.github.io/reponame`

2. Go to https://www.pwabuilder.com

3. Paste your GitHub Pages URL → click Start

4. Download → Android → it gives you a signed APK ready to install

## Troubleshooting

**"SDK not found"** — Open Android Studio, go to Tools → SDK Manager and install Android SDK 33+

**"JAVA_HOME not set"** — Android Studio installs JDK at:
- Windows: `C:\Program Files\Android\Android Studio\jbr`
- Mac: `/Applications/Android Studio.app/Contents/jbr/Contents/Home`
Set JAVA_HOME to that path.

**Game audio doesn't work on Android** — Web Audio API requires a user gesture first. The game already handles this — just tap the screen once and audio starts.

**Game looks tiny / not fullscreen** — Add the fullscreen styles above, and in `www/index.html` make sure the viewport meta tag reads:
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
```
